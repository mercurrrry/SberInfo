# SberInfo

Веб-приложение для мониторинга кредитов и финансовой информации с отображением актуальных валютных курсов.

Источники данных

- MOEX — биржевые курсы (USD, CNY)
- ЦБ РФ — официальные курсы (EUR, GBP, JPY, CHF)

Технологии

- Next.js
- React
- TypeScript
- API Routes (Next.js)
- Lucide Icons
- Shadcn/ui components

Установка
pnpm install
pnpm add lucide-react
pnpm run dev
